Questions

Which APK should I pick?

Most people should start with Standard, which installs normally. Pick Full (sideload) if you want the accessibility-based features such as Button Remap. It needs Google Play Protect scanning turned off while you install it; the install video shows how.

How do I install it on my TV?

Download the APK, then move it to the TV with a file manager app, a USB drive or a Send Files style app, and open it from the TV to install. The install video walks through it. You may need to allow installs from that app when asked.

What is the Play Protect warning?

The Full APK is sideloaded, so Google Play Protect can warn about it or block it. Turn Play Protect scanning off while you install the Full version, as shown in the install video. Standard installs like any other app from outside the Play Store.

Which TVs and devices does it work on?

Android TV and Google TV devices running Android 5.0 or newer.

Can I use it with my normal remote?

Yes. It is designed for the remote and the big screen, so the D-pad and OK button move through the dock, Control Center and Dynamic Island. Button Remap is part of the Full version.

How do I set it as my default launcher?

The install video shows how to install it and set it as your default on Android TV and Google TV.

How do I update it?

Download the newest APK from this page and install it over the current one. Version 3.3 is the current download, and 4.0 is coming soon.

How do I uninstall it?

Open your TV's Settings, go to Apps, pick tvOS Launcher and choose Uninstall. If you set it as default, choose your old home screen first. Menu names vary a little by TV.

Is it free?

Yes. It is free and needs no account.

What is coming in 4.0?

Version 4.0 is not released yet. Live info cards, the music player with synced lyrics, aerial screensavers, StandBy clocks and ADB Tools are marked “Coming in 4.0” and are not in the 3.3 download.
