Port your desktop apps to iPad.

ipadport is a command-line tool that reads a desktop app's project, tells you what will and won't work on iPadOS and iOS, and generates an adaptive iPad and iPhone Xcode project for it.

What it does ↓

Command line · Python 3.10+ · A Mac with Xcode 15+ is needed to build the result

Four things ipadport does

From source code, and honest about every feature.

AnalyzeScore the portDetects the app type and gives a score with blockers, majors and minors.
PortGenerate the Xcode projectCreates an adaptive iPad and iPhone project with Split View, Stage Manager and multiple windows.
ElectronA native bridgeKeeps file access, dialogs, clipboard, links, downloads, notifications and Electron IPC working.
ExtractRecover Electron sourceReads app.asar from an Electron app you own or may modify.
Analyze

See what will work first.

Then generate the project.

Run analyze to get a verdict, then port to write the project. Run the result on a simulator or your iPad.

  • Output as text, Markdown or JSON
  • --fail-on blocker for CI
  • Every finding listed with file, line and the fix
$ ipadport analyze examples/electron-notes
Detected:  Electron app  (strategy: web-wrapper)
Score:     88/100  (0 blockers, 1 major, 6 minor, 0 info)
Verdict:   Good candidate: should port with little or no code change.

$ ipadport port examples/electron-notes --out NotesForIPad
Generated an adaptive iPad/iPhone app project 'NotesExample'.

Questions

Can it convert any Mac or Windows program?

No. No tool can turn a compiled Mac or Windows program into a working iPad app, because iOS does not allow it. ipadport works from source code and tells you exactly where a feature needs a replacement.

What do I need to build the result?

A Mac with Xcode 15 or newer and XcodeGen. The analyze and port commands themselves run on macOS, Windows and Linux.

Does everything work out of the box?

Electron main-process code must be ported by hand into ipc-handlers.js. The tool finds every channel and generates a stub for each one.
