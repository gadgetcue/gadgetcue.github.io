Questions

Is this the official Audacity app?

No. It is a separate build of the open-source Audacity code for iPad and iPhone. The official Audacity is made by the Audacity team at audacityteam.org.

Is it finished?

Not yet. Audacity 4 itself is in beta, so expect missing features and bugs once this build is released.
